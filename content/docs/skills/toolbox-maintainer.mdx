---
title: 工具箱维护助手
description: 用同一套结构收纳新的技能、MCP 和工作流。
---

当你想把一个已经用过的能力收进仓库，可以让维护助手补齐目录、使用说明和构建检查。

## 使用方式

```bash
npm run skill:install -- toolbox-maintainer
```

在本仓库工作目录中调用：

```text
用 $toolbox-maintainer 把这个技能整理进工具箱，补齐安装说明、依赖和使用示例，检查网站可以构建。
```

## 它会检查什么

- 条目编号是否唯一，技能名称是否与目录匹配。
- 对应文档、标签、来源、依赖及使用限制是否齐全。
- 是否包含固定盘符、凭据、第三方未授权内容或私有任务样本。
- 目录生成、类型检查和静态网站构建是否通过。

新增条目需要同时维护源文件与文档；首页卡片由 registry 自动生成。配置示例必须明确标注，不能被包装成已经部署的服务。
