---
title: 漫画翻译与回填
description: 结合上下文翻译对白，按原始位置重新排版。
---

这个技能把框架和聊天模型的职责连接起来：框架提取原文并记录坐标，当前聊天负责翻译与语义复核，再将结果按编号贴回漫画。

## 适用场景

- 英语、韩语漫画译为简体中文，需要保留人物关系与原文语气。
- 已有本地 OCR 项目，希望替换不准确的机器译文。
- 长篇分批处理，需要人物术语、疑问与进度能持续保存。

## 安装与依赖

```bash
npm run skill:install -- comic-translate
```

需要 Python 3.10+ 和独立的 `swell-cartoon-translate` 框架，其版本须包含 `ctt.chat` 与 `ctt.exchange` 模块。检测、OCR 和排版的依赖在框架中安装；本工具箱不附带模型权重或漫画素材。

Windows PowerShell 中指定框架位置：

```powershell
$env:CTT_REPO = "D:\Projects\swell-cartoon-translate"
```

也可以在技能脚本调用时使用 `--repo`。这里不预设机器盘符，换电脑时保持相同的配置方式即可。

## 一句话调用

```text
用 $comic-translate 翻译这个目录的第5话，结合上下文、保留原文语气，检查后放到新文件夹。
```

## 它会完成什么

1. 确认范围，使用已有匹配项目或重新检测、识别文字。
2. 保存图片、对白编号和坐标，按场景分批翻译。
3. 核对说话者、动作对象、称呼、否定句和多义词。
4. 检查漏句、编号及原图摘要，生成新图片和可编辑项目。
5. 保留人物术语、疑问标注、原文译文对照页与处理进度。

## 质量与限制

自动检查可以发现漏句、错用翻译包、原图变化与部分排版问题，不能证明语义完全正确。看不清的 OCR、无法确认的指代会写入 notes，不能为了通顺而编造内容。

译文保留原文的表达尺度，不擅自强化、删减情节。当前模型适用规则仍然有效。成品始终输出到新目录，原图与旧译文保留。
