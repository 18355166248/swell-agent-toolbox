## 三种不同的积累

| 类型 | 主要作用 | 这里放什么 |
| --- | --- | --- |
| Skills | 给智能体一套可复用的方法 | SKILL.md、脚本、必要的参考资料 |
| MCP | 连接真实的工具和数据 | 自有服务，或注明来源的配置示例 |
| Workflows | 将多个能力组织成任务 | 前置条件、处理顺序、检查与恢复方法 |

当前目录中的 MCP 是配置示例，工作流是可执行的操作指南，不等同于已部署服务。可在首页按类型、标签或关键词查找。

## 这套工具箱如何维护

条目元数据保存在 `registry.json`，首页和可下载的目录数据由它生成。技能本身保留标准目录结构，使用说明独立写在文档中。私人配置、访问密钥和任务样本不属于公开内容。
